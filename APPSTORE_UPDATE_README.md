# Iumrah — окно обновления App Store

Патч для `kepler-ios-main(8).zip`. Архив содержит только изменённые и новые файлы с путями от корня репозитория.

## Установка

1. Загрузите `iumrah-beta-update-appstore-modal-20260930.zip` в корень GitHub-репозитория. Это имя соответствует существующему `apply-beta-update.yml`.
2. Дождитесь применения ZIP, затем запустите существующий workflow `Iumrah — TestFlight`.
3. Проверка ориентируется на опубликованный продукт App Store `6759577859`, bundle ID `com.iumrah.app`. TestFlight сам по себе не публикует новую версию в App Store.

## Поведение

- Запрос начинается только после завершения заставки и онбординга, когда приложение активно; затем есть дополнительная пауза 1 секунду для завершения анимаций.
- Функция не выполняет работу в `App.init`, не ждёт ответа сервера для показа главного экрана и не зависит от восстановления аккаунта или загрузки отелей.
- Запрос использует страну текущего App Store. Если StoreKit не сообщает страну, используется регион устройства; последний резерв — UZ. Встроенная таблица переводит ISO alpha-3 в alpha-2.
- Установленная версия берётся из `CFBundleShortVersionString`. Сравнение числовое: `2.0.10 > 2.0.9`, `2.0 == 2.0.0`. Более старые и равные версии не показываются, в том числе при использовании более нового TestFlight.
- Проверяются ID продукта, bundle ID и минимальная версия iOS. Несовместимое с устройством обновление не предлагается.
- Новый запуск проверяет App Store заново. Возвращение из фона или на основной экран может повторить проверку; успешный ответ сохраняется в памяти на 6 часов. После сетевой ошибки следующая такая попытка разрешена через 60 секунд.
- Таймаут запроса 6 секунд, всей загрузки — 10 секунд. Нет интернета, ошибка Apple и повреждённый ответ не открывают окно и не блокируют приложение. При уходе в фон задача отменяется.
- Окно ждёт закрытия других модальных окон и не открывается в погружённом режиме или во внутренних разделах навигации.
- Та же версия предлагается не чаще одного раза в 24 часа. Другая новая версия может быть предложена сразу. Кнопка «Позже» и закрытие жестом доступны.
- В окне — точная основная иконка из AppIcon, название Iumrah, обе версии, кнопка с символом App Store. Поддержаны RU, EN, UZ Latin и UZ Cyrillic, тема приложения и Dynamic Type. Кнопки закреплены снизу, содержимое прокручивается.
- Кнопка ведёт на известную страницу Iumrah в App Store. Если система не смогла открыть ссылку, появляется объяснение с возможностью повторить попытку.

Версия релиза в `project.yml` не менялась: `2.0.5`. Когда опубликованная версия равна установленной или ниже, отсутствие окна — ожидаемое поведение.

## Проверка

В среде подготовки не было Xcode, Swift-компилятора и симулятора iOS. Сборка, запуск приложения, автоматические Swift-проверки и визуальная проверка на устройстве здесь не выполнялись.

Выполнены: синтаксический разбор изменённого Swift-кода с сопоставлением исходного RootView, проверка ссылок на ассеты, конфигурации XcodeGen, ISO-таблицы и точности наложения ZIP на исходный проект. Существующую конструкцию `if let ... = try? await ...` сторонний парсер отмечает и в оригинальном RootView; новых таких ошибок нет.

Для Swift-проверок без подписи и подключения к сети:

```bash
bash scripts/check-app-store-update.sh
```

Набор проверяет числовое сравнение версий, ответы другого приложения, минимальную iOS, повреждённый JSON, ссылку на App Store, выбор страны и ограничение повторов.

После сборки на iPhone 11 / 13 mini и iPad проверьте: запуск без сети, завершение первого онбординга, переход в фон, отсутствие запроса для текущей/более новой версии, появление окна на старой установленной версии, закрытие кнопкой/жестом, переход в App Store и крупный текст. Для фактического показа должна существовать более новая совместимая версия в App Store; фиктивного обновления в релизной сборке нет.
